## Task 1: 建立设计系统和基础CSS框架
**描述**: 创建统一的设计系统CSS文件，包含变量、工具类、组件样式
**详细要求**:
- 创建 `static/css/design-system.css`，包含：
  - CSS变量定义（颜色、字体、间距、阴影）
  - 基础重置样式
  - 工具类（布局、间距、文字）
  - 组件类（按钮、卡片、表单、标签）
- 创建 `static/css/common.css`，包含：
  - 导航栏样式
  - 页面布局框架
  - 响应式基础
- 确保所有CSS类名遵循BEM命名规范
**验收标准**:
- [ ] design-system.css 包含所有设计变量
- [ ] common.css 包含导航和布局样式
- [ ] 在测试HTML中可以正确应用样式
